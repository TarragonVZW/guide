Our Discord is the primary hub for announcements and community events.

### Bot Commands (YAGPDB)
Dragons can use Jasper's custom command to manage groups:

- **Setup Group:** `-setupGroup "groupName" slots` (Users react to join)
- **Delete Group:** React with ❌ to the message.

### Database Commands
- **Get Database:** `-getGuildDb` (Limited storage!)
- **Clear Database:** `-CLEARDB` (Emergency only!)

### Admin Forum
Each event and post must have a forum post in the `#admin-forum` channel.
- Graphics and copywriting coordination happens here.
- Event details (Venturer, photographer, etc.) are recorded here.
