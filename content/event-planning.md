### Types of Events
- **Regular:** Standard meetups (Het Textielhuis).
- **Special:** Themed events (Wizarding Exam, Casino Nights).
- **Target Ratio:** 1/3rd special events during the academic year.

### Planning Timeline
- **Big events:** Plan 2 weeks ahead.
- **Regular special events:** Plan 1 week ahead.

### Event Roles
- **Venturer:** The main contact point and person responsible for the event.
- **Photographer:** Takes photos and uploads usable ones to the Google Drive (filter them first!).
- **Volunteer:** Recruited per event.

### Planning Checklist
- [ ] Assign a Venturer
- [ ] Create `#admin-forum` post
- [ ] Create Discord Event
- [ ] **Post to Website:** All special events (excluding "Open Game Nights") must be added via [TinaCMS](https://tarragon.be/admin). 
    - *Note: If you don't have the login, ask in the `#admin-channel`.*
- [ ] Post to Instagram & Facebook
- [ ] Check Legal Requirements
- [ ] Arrangements with Third Parties (Sponsors, etc.)
